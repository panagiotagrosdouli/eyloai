# EYLO Product Completion Register

**As of 2026-11-12.** This is an evidence register, not a completion score. “In an open PR” means code is not integrated into `main`. Existing source files and passing CI do not establish a complete product. No product is marked production-ready by this register.

## Shared release gates

- **Frontend / workflow:** a user can discover, start, create, work, save, return, continue, complete and export/share a useful task; UX, mobile and accessibility review must be recorded.
- **Backend / database:** migrations are applied to the intended staging project; persistence survives reloads; errors, concurrency and recovery are verified.
- **Security:** test actual RLS, owner/tenant boundaries and at least two users against the intended staging project. A migration policy or fixture test alone is not live acceptance.
- **Tests:** link exact unit/integration/browser/export/security evidence. Mock or fixture results are labeled as such.
- **Staging / production:** currently **not accepted / not verified** unless a product row links a real dated probe. No production readiness is claimed here.
- **Unknown means not audited**, not that code definitely does not exist. Replace this state only after checking the relevant route, service, migration, tests and provider configuration.
