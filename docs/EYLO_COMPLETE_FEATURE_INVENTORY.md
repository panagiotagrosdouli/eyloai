## Verification vocabulary

- **NOT TESTED:** no relevant behavior has been exercised with recorded evidence.
- **WORKING:** observed happy path only; edge cases and security not yet proven.
- **PARTIAL:** some behavior/code exists but an essential aspect is missing or blocked.
- **BROKEN:** exercised and failed.
- **MISSING:** required behavior not implemented.
- **BLOCKED:** verification requires unavailable infrastructure/credentials/approved access.
- **VERIFIED COMPLETE:** function-level success, failure, auth, persistence, accessibility and regression test results are recorded.
